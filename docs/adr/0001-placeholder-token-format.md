# ADR-0001：占位符 token 保留 Unicode 私有区（PUA）

- 状态：已接受
- 日期：2026-11-04
- 相关：PRD FR-13、`docs/contracts/prompt-contract.md` §6/§8.2、B-07 评测集

## 背景

句子模式送模型前，主进程把行内代码、URL、文件路径、CLI 参数、标识符、版本号替换为占位符，返回后还原。PRD FR-13 规定格式为 `\uE000n\uE001`（Unicode 私有区，PUA）。

本轮比较了 ASCII 占位符的可行性，候选包括 `{{0}}`、`[[0]]`、`[[SW0]]`、`[[SW7f3a0]]`。核心权衡：

| 维度             | PUA `\uE0000\uE001`            | ASCII `{{0}}` / `[[SW0]]`              |
| ---------------- | ------------------------------ | -------------------------------------- |
| 模型改写概率     | 低：稀有字符，模型没有改写先验 | 中：可能被当模板语法、被翻译、被转全角 |
| 源文本冲突       | 接近 0                         | 需要 nonce 或转义                      |
| 代理 / JSON 兼容 | 少数代理可能丢字符             | 最稳                                   |
| 流式观感         | 空白 / 豆腐块                  | 可见，但会闪 `[[SW0]]`                 |
| 日志与调试       | 难，日志里不可见               | 易                                     |
| token 成本       | 低                             | 略高                                   |

沉浸式翻译使用 `{{1}}` 处理 HTML 标签，是因为模型熟悉“标签占位符”这个约定；Snapword 保护的是代码标识符、URL、路径，场景不同，不能直接照搬。

## 决策

1. MVP 继续使用 PUA token `\uE000<index>\uE001`，不切换到 ASCII。
2. 流式还原的具体算法不在本 ADR 决定；契约只约定不变量：**不得把半截占位符渲染给用户**。结束后一次性还原或尾部缓冲（只扣住可能构成占位符的尾部字符）都可以，留给 B-04 修订与实现决定。
3. B-07 评测集增加 A/B 组，比较三种格式的占位符还原成功率、模型改写率、代理/JSON 兼容性：
   - A：PUA `\uE0000\uE001`
   - B：`[[SW0]]`
   - C：`[[SW7f3a0]]`（带 per-request nonce）
4. 只有同时满足以下条件，才重新评估切换 ASCII：
   - ASCII 组还原成功率 ≥ PUA 组，且 ≥99%；
   - 目标服务/代理无丢字符、转义或全角化问题；
   - 同步修改 PRD FR-13 与 B-04 §6/§8.2。

## 理由

- PUA 字符稀有，模型没有“翻译/改写”它们的先验；ASCII 的 `{{...}}` 容易被当成 Jinja/Handlebars 模板。
- PUA 与源文本冲突概率接近 0；ASCII 需要 nonce 或转义，增加匹配与还原复杂度。
- PUA 的代价是流式观感和日志可读性：
  - 观感问题用“不得渲染半截占位符”的不变量解决，不需要改协议；
  - 日志问题通过记录 `index → 原文` 映射解决，不需要把原文写进日志。
- 当前没有实测数据证明 ASCII 的还原率更高，先不为了“看得见”牺牲模型保真。

## 后果

- B-04 §6.2 保持 PUA 格式；§8.2 补充“不得渲染半截占位符”的约束。
- 单词模式不使用占位符（已决定“占位符只用于句子模式”）。
- B-07 评测集增加 A/B 组；未跑完前不切换格式。
- 若未来切换 ASCII，需要同步修改 PRD FR-13、B-04 §6/§8.2、测试向量与还原正则。

## 备选方案

- `{{0}}`：与 Jinja/Handlebars 模板语法冲突，否决。
- `[[0]]`：与 wiki 链接语法冲突，否决。
- `[[SW0]]` / `[[SW7f3a0]]`：可读、代理安全，但模型改写率与源文本冲突风险待评测；暂不采用。
